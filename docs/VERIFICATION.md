# 검증 기록

- TypeScript 검사와 Vite 프로덕션 빌드 통과.
- 엔진 테스트 8개 통과: 재화, 탐험, 성장, 에너지 부족, 오프라인 상한, 목표 보상, 서식지 구매, 저장 검증, 도감 수집.
- 실제 브라우저에서 먹이 주기(꽃잎 -5 / 포만감 증가 / 경험치 +8), 탐험(꽃잎 +18 / 도감 +1), 새로고침 후 저장 복원을 확인.
- 모바일 화면과 1440px PC 화면으로 반응형 배치 및 생성 이미지 로딩 확인.
- 네이티브 프로젝트를 생성했으며 배포용 서명과 앱스토어 등록은 별도입니다.

GitHub Actions의 상태와 APK 아티팩트는 해당 커밋의 실행 결과를 기준으로 확인하세요.

## v0.2 실시간 3D — 2026-09-26

- 엔진 8개 + GLB 구조/리그 2개, 총 10개 테스트 통과.
- TypeScript/Vite 빌드와 Android·iOS Capacitor 동기화 통과.
- Higgsfield Blender 렌더와 실제 브라우저에서 모델을 각각 육안 검증.
- 390px 모바일 및 1440px 데스크톱에서 정원 로딩·배치를 확인.

- 실제 3D 연못 클릭 시 청결 30 증가, 꽃잎 8개 보상 확인.
- 모델 4,144,664 bytes, 외부 텍스처 의존 없음. 환경 병합 후 모바일 뷰에서 draw calls 118, triangles 313,662 관측(프레임당 보고 수치; 기기 FPS 벤치마크는 아님).
- Blender 편집 원본과 모델링 스크립트도 저장소에 포함.
