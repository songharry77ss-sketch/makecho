# makecho 3D 에셋 제작 기록

2026-09-26부터 메인 정원과 탐험 화면은 Three.js + GLB 실시간 3D를 사용합니다.

## 원본과 사용 방식

- 제작 도구: Higgsfield 3D Jutsu / Blender 5.2
- 프로젝트: https://higgsfield.ai/3d-jutsu/8c7afda8-4d2f-4330-9a8f-67d52f68f5b3
- 재현 가능한 모델링 스크립트: `scripts/create-garden-blender.py`
- 게임용 모델: `public/assets/models/makecho-garden.glb`
- Blender 편집 원본: `art-source/makecho-garden.blend`
- 라이브 뷰어: `src/Garden3D.tsx`
- 검증된 Blender 미리보기: `docs/makecho-3d-preview.png`
- 확정 revision: 1 / 821개 메시 / GLB 4,144,664 bytes

타사 유료 에셋을 구매하거나 출처 불명 모델을 복사하지 않고 프로젝트 전용으로 직접 모델링했습니다. 둥근 장난감 같은 형태와 재질을 사용합니다.

## 15개 에셋 종류

초파리(몸·머리·눈·더듬이·6개 다리·2개 날개), 통나무 섬, 이끼 쿠션, 나무, 고사리, 풀, 조약돌, 데이지, 버섯, 딸기, 연못, 수련 잎과 꽃, 잎 침대, 떨어진 나뭇가지, 이슬 결정.

## 상호작용

- 드래그: 정원 회전, 휠/핀치 또는 버튼: 확대·축소
- 모모 클릭: 놀아 주기
- 딸기 주변 클릭: 먹이 주기
- 연못 주변 클릭: 청소
- 잎 침대 클릭: 휴식
- 빈 땅 클릭: 해당 지점으로 비행
- 돌봄 버튼: 동일한 게임 행동과 비행·날개 애니메이션 연결
- 세 서식지: 같은 모델에 서로 다른 조명·안개·배경·반딧불 설정

## 성능과 복구

정적 환경 메시를 재질별로 병합하고, 모모의 날개는 별도 노드로 유지합니다. 작은 입자는 인스턴싱을 사용합니다. 모바일은 픽셀 비율 1.5와 렌더링 30fps를 상한으로 둡니다. 화면 밖 또는 숨겨진 탭에서는 그리기를 건너뜁니다. 저동작 환경설정에 맞춰 자동 애니메이션을 끕니다. 화면 이동 시 지오메트리·재질·텍스처·렌더러를 정리합니다.

WebGL 초기화 실패, 모델 로드 실패 또는 그래픽 컨텍스트 손실 시 기존 생성 일러스트를 표시하고 돌봄 버튼으로 플레이를 유지합니다. 3D 재시도 버튼을 제공합니다. 이 경우 실시간 3D라고 표시하지 않습니다.

생성 일러스트는 이제 프로필과 3D 미지원 환경의 대체 화면으로 사용합니다. 실제 커넥톰 시뮬레이션에 대한 범위는 `SCIENCE.md`와 같습니다.
