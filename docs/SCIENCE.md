# 과학적 근거와 한계

## 공개된 데이터

- [FlyWire](https://flywire.ai/): 성체 초파리 뇌 연결 지도 프로젝트.
- [Dorkenwald et al., Nature (2024), Neuronal wiring diagram of an adult brain](https://www.nature.com/articles/s41586-024-07558-y): 교정된 신경세포 139,255개를 기술한 원 논문.
- [FlyWire Codex](https://codex.flywire.ai/): 뉴런, 세포 분류, 연결 탐색과 공개 데이터 다운로드. 여기서 말하는 Codex는 게임을 개발한 도구와 별개의 신경과학 사이트입니다.
- [Whole-brain connectivity, Zenodo](https://zenodo.org/records/10676866): 연결 데이터 아카이브. 전체 시냅스 파일은 기가바이트 단위이므로 게임 번들에 포함하지 않았습니다.

숫자는 2024년 FAFB 연구를 설명하며, 모든 최신 FlyWire 데이터셋에 공통된 숫자가 아닙니다.

## 현재 게임이 하는 일

뇌 관찰실은 감각 입력, 처리, 행동 출력이라는 개념을 설명하는 합성 도식입니다. 노드 위치와 선은 UI용으로 직접 생성했고, 측정된 뉴런이나 실제 신호 강도를 뜻하지 않습니다. 플레이 상태는 `src/engine.ts`의 규칙으로 업데이트합니다.

## 실제 커넥톰 통합에 필요한 후속 단계

1. 사용할 공개 릴리스·데이터셋을 고정하고 데이터별 라이선스와 재배포 조건 확인.
2. 목표 행동(예: 후각 접근)에 맞는 세포 ID·영역·연결 부분집합을 검증해 추출.
3. 연결 가중치 외에 신경전달물질, 시냅스 부호, 시간상수, 발화 모형, 감각 및 운동 경계를 정의.
4. 검증된 실행 모형과 게임의 귀여운 연출을 분리하고, 생물학적 타당성 테스트 추가.
5. 브라우저용 축소 모형과 연구용 서버 실행을 각각 검증.

커넥톰 구조만으로 개별 생명체의 기억·의식·동일성이 복원되는 것은 아닙니다. 이 게임은 그러한 주장을 하지 않습니다.
